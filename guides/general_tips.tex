\begin{itemize}
    \item \textbf{Division}: Do as little division as possible; prefer multiplication and modular inverse.
    \item \textbf{Floating Point Precision}: \texttt{float} (least) $<$ \texttt{double} $<$ \texttt{long double} (most).
    \item \textbf{Float Comparisons}: Never use \texttt{a == b}; always use \texttt{fabs(a - b) < 1e-9}.
    \item \textbf{Integer Overflow}: Watch for $N \cdot (N - 1) / 2$, large sums, powers, and bit shifts (\texttt{1LL << k}).
    \item \textbf{Binary Search Precision}: Using a fixed number of iterations (e.g. 80--100) is far more reliable than \texttt{while (hi - lo > eps)}.
    \item \textbf{Bounds Check}: Out of bounds and negative indices cause silent RTE / WA. Check graph index 1 vs 0.
    \item \textbf{Loop Variables}: Never shadow outer loop variables in inner loops (\texttt{i}, \texttt{j}).
    \item \textbf{Randomization Trick}: To bypass anti-hash/anti-quicksort test cases, shuffle with high-precision clock:
    \begin{itemize}
        \item \texttt{auto s = chrono::steady\_clock::now();}
        \item \texttt{mt19937\_64 rng(s.time\_since\_epoch().count());}
        \item \texttt{shuffle(a.begin(), a.end(), rng);}
    \end{itemize}
    \item \textbf{Trigonometry}: \texttt{sin}, \texttt{cos}, \texttt{atan2} work with radians. To convert: $\text{deg} = \text{rad} \cdot \frac{180}{\pi}$, $\text{rad} = \text{deg} \cdot \frac{\pi}{180}$.
    \item \textbf{Modulo Properties}:
    \begin{itemize}
        \item $(a + b) \pmod m = ((a \bmod m) + (b \bmod m)) \bmod m$
        \item $(a - b) \pmod m = ((a \bmod m) - (b \bmod m) + m) \bmod m$
        \item $(a \cdot b) \pmod m = ((a \bmod m) \cdot (b \bmod m)) \bmod m$
        \item $(a / b) \pmod m = (a \cdot b^{m - 2}) \bmod m \quad (\text{for prime } m)$
        \item If $a \bmod k = b \bmod k$, then $(a - b) \bmod k = 0$.
    \end{itemize}
    \item \textbf{Heavy-Light String Trick}: If string length $> \sqrt{\text{max\_length}}$, use polynomial hashing; else use Trie.
\end{itemize}
